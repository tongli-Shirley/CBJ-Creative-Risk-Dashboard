CBJ 素材差异度与侵权风险看板
================================

打开方式
--------
1. 请先完整解压收到的 ZIP 文件。
2. 打开“CBJ素材差异度与侵权风险看板”文件夹。
3. 双击 index.html，使用 Chrome、Edge 或 Safari 打开。

查看素材
--------
- 每组按“原素材 / 复刻视频 / Playable”对应展示。
- 视频可直接点击播放控件预览。
- Playable 显示在右侧预览区，可在画面内点击体验。
- 如果浏览器限制本地 Playable 交互，请改用 Chrome，或把完整文件夹上传到企业网盘的静态网页服务后访问。

转发要求
--------
- 推荐直接转发外层 ZIP 文件，避免漏发视频或 Playable。
- 不要只发送 index.html；同目录内的 MP4 和其他 HTML 文件都是报告的一部分。
- 本报告可离线阅读，Playable 内部若引用第三方调试脚本，离线时不影响报告正文和本地素材。

内容范围
--------
- 8 组素材差异度与侵权风险分析
- 原素材、复刻视频和对应 Playable 直接预览
- 8 月投放消耗及占比
- 差异度判定方法和投放建议

审查边界
--------
本看板用于投放前风险筛查，不替代律师正式法律意见。
